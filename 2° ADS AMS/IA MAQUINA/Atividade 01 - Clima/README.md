# Temperatura de Cidades 🌤️

Bem-vindo ao projeto **Temperatura de Cidades**!

Este projeto foi desenvolvido utilizando **Java** com o objetivo de consultar e exibir informações climáticas de diferentes cidades em tempo real.

A aplicação permite que o usuário digite o nome de uma cidade e visualize dados relacionados à temperatura, proporcionando uma experiência simples, prática e intuitiva.

---

# Histórico

A ideia do projeto surgiu como uma forma de praticar conceitos fundamentais da linguagem Java.

O aplicativo foi desenvolvido com foco em:

- Programação Orientada a Objetos;
- Manipulação de dados;
- Entrada de informações pelo usuário;
- Organização de código;
- Desenvolvimento de aplicações Java.

Além disso, o projeto auxilia no entendimento de comunicação entre sistemas e obtenção de dados em tempo real.

---

# Modelo

O aplicativo segue um modelo simples de consulta climática:

1. O usuário informa o nome de uma cidade;
2. Os dados retornados são processados;
3. As informações climáticas são exibidas ao usuário.

Esse modelo permite consultas rápidas e práticas de temperatura e condições climáticas.

---

# Funcionalidades

O projeto possui as seguintes funcionalidades:

## Consulta de Temperatura

Permite pesquisar a temperatura atual de diferentes cidades.

## Busca por Cidade

O usuário pode informar o nome da cidade desejada.

## Exibição de Informações Climáticas

Os dados exibidos podem incluir:

- Temperatura atual;
- Nome da cidade;
- Condição climática;
- Umidade do ar;
- Sensação térmica.
